# Tracker Layout Project

This project recreates a modern tracker dashboard using HTML and CSS. The page is designed to demonstrate responsive layout techniques with Flexbox and CSS Grid while keeping the interface clean and professional.

## What is built

The page includes:

- a left sidebar navigation for the tracker app
- a top summary bar with action buttons
- four statistic cards for key workload information
- a progress overview panel with colored status bars
- a daily schedule list
- a focus panel with task status items
- a recent activity section
- a milestone board with cards for major goals

## File structure

- `index.html` – the full page structure and content
- `style.css` – all layout styling, colors, spacing, and responsive design rules

## What each part does

### `index.html`
This file holds the dashboard structure. It contains the sidebar, header, stat cards, panels, and content sections that make up the tracker layout.

### `style.css`
This file controls the visual design and layout of the page. It uses Flexbox for alignment and layout inside components such as the topbar, navigation, and stat cards, and Grid for arranging the main dashboard sections and columns.

## How to view the project

Open `index.html` in a browser to see the page. You can also run a local server from the project folder if you want a browser preview.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
